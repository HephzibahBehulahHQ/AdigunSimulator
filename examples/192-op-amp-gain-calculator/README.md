# Example 192 — Op-amp gain calculator

## Objective
Calculate ideal inverting and non-inverting closed-loop gain from feedback and input/ground resistor values.

## Run and expected result
An inverting stage with Rf = 100 kΩ and Rin = 10 kΩ has gain −10. A non-inverting stage with Rf = 90 kΩ and Rg = 10 kΩ has gain +10. Equal 10 kΩ values produce non-inverting gain +2. Zero, negative, non-finite, or unsupported inputs are rejected.

## Limits
These are ideal equations. Real op-amp gain depends on bandwidth, supply rails, input characteristics, output load, slew rate, stability, and component tolerances.
