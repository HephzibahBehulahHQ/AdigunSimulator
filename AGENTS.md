# AdigunSimulator engineering rules

- Keep all product code in this repository.
- Never represent a visual placeholder, unsupported simulator result, generic symbol, or unverified part as an engineering fact.
- Keep component identity, pin maps, nets, view layouts, validation and history in the native project document.
- Do not add server-side AI, authentication, cloud sync, billing, deployment secrets, or external component data without documented approval and tests.
- Every enabled UI command needs an accessible name, an implemented action, and test coverage proportionate to risk.
- Record implementation, test evidence, known limits and migrations truthfully.
