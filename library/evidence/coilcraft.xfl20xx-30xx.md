# Coilcraft XFL20xx and XFL30xx ordering evidence

- [XFL2005](https://www.coilcraft.com/en-us/products/power/shielded-inductors/molded-inductor/xfl/xfl2005/). 14 order codes.
- [XFL2006](https://www.coilcraft.com/en-us/products/power/shielded-inductors/molded-inductor/xfl/xfl2006/). 16 order codes.
- [XFL2010](https://www.coilcraft.com/en-us/products/power/shielded-inductors/molded-inductor/xfl/xfl2010/). 23 order codes.
- [XFL3010](https://www.coilcraft.com/en-us/products/power/shielded-inductors/molded-inductor/xfl/xfl3010/). 18 order codes.
- [XFL3012](https://www.coilcraft.com/en-us/products/power/shielded-inductors/molded-inductor/xfl/xfl3012/). 20 order codes.

These tables support the exact MEC order codes, nominal inductance in microhenries, and ±20% tolerance. Lifecycle and independent review remain pending.

The native footprint uses Coilcraft’s recommended lands for each series. Local pad 1 follows the winding-start dot. XFL2010 is rotated 180° from the manufacturer drawing to keep the winding-start pad on the same side as the other footprints. Earlier XFL2005 and XFL2006 parts may lack that dot. XFL3010 and XFL3012 parts made before June 2018 may use different markings.

One native fixture per series checks ideal RL analysis, PCB routing and fabrication exports, and the breadboard breakout diagnostic.
