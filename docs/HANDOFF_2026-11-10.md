## Oscilloscope: important behavior

- LED current limiter uses steady DC. VCC = 5 V and LED_A = 2 V in the current fixed-drop model; a horizontal line is correct. Do not fabricate oscillation to make it look active. Step is intentionally unavailable for a DC operating point.
- A reproduced bug gated the entire playback engine behind Live feedback. It is fixed: the renamed **Canvas feedback** switch controls only canvas highlighting, while Run always supplies playback and scope data. Toggling it preserves the current paused sample.
- RC/RL records use the same successful first-order model and original initial conditions at 501 display timestamps. They are analytical curves, not a general SPICE transient solution. Explicit linear RLC mode remains separate.
- Pause/Step operate on recorded time samples; playback completes after the finite recording. Run can replay. Unsupported reports/calculators do not acquire invented waveforms.
- Key files: `js/analytical-scope-recording.mjs`, `js/simulation-feedback-timeline.mjs`, `js/simulation-playback.mjs`, `js/oscilloscope-data.mjs`, `js/scope-readout.mjs`, `js/design-tools-ui.mjs`, and HUD/run handlers in `app.js`.

## SPICE investigation already performed — do not repeat downloads blindly

The owner explicitly approved reading official ngspice source and TI comparator model files. Upstream inspection files are outside the product repository in sibling `upstream-review`; nothing from those downloads is shipped.

- Official source: `https://git.code.sf.net/p/ngspice/ngspice`, tag `ngspice-47`, verified commit **a80f6e3e95d51534905b1f23410a951802666656**. Shallow checkout: `upstream-review/ngspice-47-source`.
- The downloaded `ngspice-47.tar.gz` is HTML, not a valid archive. It failed the published hash check. Do not execute or use it. The verified Git checkout supersedes it.
- `COPYING` is not BSD-only: frontend numparam is LGPL, other optional portions have additional licenses. Select build options deliberately and satisfy corresponding-source/notices requirements before redistributing a binary/WASM build.
- TI TINA archive: `https://www.ti.com/lit/zip/SLCM004`, SHA256 `07588472e316f9cf0bf49ce8eb30737274d4aa641be2c351d543ba5293cc42e6`.
- TI PSpice archive: `https://www.ti.com/lit/zip/SLCJ016`, SHA256 `2b32be0bebb6a3c9bcc93e2a6d9ba1e359c2dcfc34dc43e396798e22bda980d8`.
- Both downloads contain a macro headed **LM2903B**, despite the LM393/LM393B download labels. The PSpice `lm393.lib` declares `LM2903B IN+ IN- Vcc GND OUT`; its header lists Iq, propagation delay, common-mode and supply ranges, hysteresis, input bias and offset. - TI's archive says all rights reserved and supplies an as-is disclaimer; redistribution permission has not been established. Do not vendor it into the public application yet.
- Local ngspice/emcc/clang/cmake/gcc/make were not available on PATH. WSL returned access denied; Docker's Linux daemon was absent. Do not bypass these restrictions.
