# Net-class editor and compatible rule review — 2026-11-09

PCB → Net Classes & Rules supports creating, renaming, editing and removing classes, selecting member nets, and applying/removing symmetric class-pair clearance rules. Selecting members reassigns those nets from other classes; removing a class removes only its pair rules and informational route tags. Unassigned nets use board rules. Every applied change has one native undo step; failed, cancelled, stale and unchanged edits preserve history. Copper geometry, native nets and component identity stay unchanged.

The shared policy reader supports the checked-in `id/traceWidthMm/clearanceMm` and `name/minimumWidthMm/minimumClearanceMm` formats. Editing retains stable identity, synchronizes legacy numeric aliases, preserves unrelated metadata and normalizes pair references before renaming. Duplicate/ambiguous class aliases, duplicate symmetric rules, unknown class/net references, invalid numbers and malformed containers are rejected. Up to 64 classes and 2080 unique unordered pairs including same-class pairs are supported. Existing overlapping class memberships use the strictest effective limits; the editor reassigns selected members exclusively.

Routing, copper audits and fabrication export use the shared validated definitions. Board minima cannot be relaxed by class/pair values. Stricter edits may reveal violations; the dialog reports the check result and export remains blocked. A same-class pair checks different electrical nets, never a route or net against itself. The CSV rule review accepts both legacy formats, accounts for board floors/unassigned nets and bounds its segment-pair work. This fixes export-pack rejection of the existing relay, audio and buck examples caused by their alternate class format.

Ten new automated tests cover legacy manufacturing packs, native geometry/connectivity preservation, reassignment, rename/no-op, deletion cascades, symmetric updates with retained metadata, same-class comparison, malformed definitions, shared enforcement, report work limits and controller history/staleness/escaping.
