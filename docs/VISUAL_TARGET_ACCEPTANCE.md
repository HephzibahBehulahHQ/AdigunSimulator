# Mandatory interface acceptance targets

The owner reaffirmed on 2026-11-09 that the client will accept nothing below these three reference interfaces. They remain mandatory product acceptance criteria; publishing a tested incremental release does not establish visual acceptance.

| View | Authoritative repository reference |
| --- | --- |
| Breadboard | [Breadboard target](../adigun%20simulator%20breadboard%20target%20interface.png) |
| PCB | [PCB target](../adigun%20simulator%20pcb%20target%20interface.png) |
| Schematic | [Schematic target](../adigun%20simulator%20schemnatic%20target%20interface.png) |

Acceptance requires rendered comparisons of all three views at the reference size (1586 × 992), plus desktop/mobile checks. Preserve AdigunSimulator / HB Elektroniker branding, navy/cyan surfaces, legible menus and icons, the categorized component sidebar, view tabs, detailed board/component/wire rendering, right properties/net information and lower simulation results/waveforms. Responsive layouts must retain usable controls without overlap or clipped content. The compact account/language controls remain required.

Use actual native project data for rendering and actual supported engine results for instruments. Do not imitate a result by hardcoding the reference values or claim verified components, firmware simulation or manufacturing qualification from appearance. The empty startup canvas requirement remains in force; users explicitly load examples to populate the views.

Status: reference images inspected and retained unchanged. A final side-by-side visual acceptance pass remains open; automated checks and incremental release approval alone do not close it.
