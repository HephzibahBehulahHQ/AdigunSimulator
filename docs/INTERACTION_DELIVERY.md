## Native freeform wires and continuation — 2026-11-10

The native project now retains optional `schematicWires` records: stable ID, source pin, destination pin or a dangling endpoint, and editable intermediate drawing coordinates. Completed routes correspond to native electrical edges; dangling wires do not silently join nets. Existing projects keep automatic orthogonal obstacle routing until the user explicitly reshapes a wire. Manual freeform routes can be diagonal; this reconciles the earlier freeform requirement with the newer reference's orthogonal default without replacing the original template.

Start at a named pin, click the canvas for bends, and finish at another named pin. Escape, right-click or Pause wire saves the current dangling endpoint. Clicking its hollow endpoint or using Resume continues at that position. Cancel drawing is separate and discards only the active preview; cancelling a resumed path preserves the saved dangling wire. Switching views pauses an active route. Explicitly clicking another dangling endpoint joins the two wires. Split wire opens the longest eligible segment with a 16-unit gap so both endpoints remain individually selectable; original net names are retained when the two halves are rejoined and that name remains available. Delete wire uses the native edge graph and prunes obsolete geometry. Component deletion, pin disconnection and breadboard reconciliation also remove stale route records.

Selecting a wire opens its Properties panel with native endpoints, net identity, calculated current/voltage when available, and editable waypoint coordinates. Double-click adds a point, Alt-click/Delete removes a focused point, and waypoint handles support dragging and keyboard arrows. Typed coordinates update immediately and coalesce one field-edit history entry. Pointer cancellation restores the previous document and dirty state; completed drags commit one Undo entry. Native save/load and Undo/Redo preserve routes. These are drawing units, not PCB millimeters. Editing a manual path does not claim automatic component clearance.

Crossing bridges now use intersections of the actual polyline segments, including diagonals, rather than endpoint chords. Their arcs are visual only and do not merge nets. Endpoint touches and parallel segments do not create junctions. Geometry has explicit resource limits: 5000 stored routes, 512 bends per route and 100000 crossing comparisons per render; exceeding the crossing budget shows a warning instead of pretending every crossing was reviewed. A hollow open endpoint is not an electrical junction dot.
